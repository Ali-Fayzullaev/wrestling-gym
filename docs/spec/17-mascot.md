# 17. Персонаж с эмоциями на всех экранах

Статус: in-progress
Зависит от: 04, 16, D-15
Ветка: `step/17-mascot`
Навыки: `ui-ux-design`, `browser-verification`

## Цель

Сервис узнаваемый и живой: свой персонаж, юный борец в шлеме-наушниках и красном трико, встречает на входе, стоит в шапке основных экранов и в каждом пустом состоянии. Эмоция совпадает с ситуацией. Скорость не меняется: персонаж это обычная SVG-картинка без JavaScript.

## Что входит

- Генератор `scripts/mascot/build.mts` (`pnpm mascot:build`) рисует 8 эмоций из общих частей в `public/mascot/<mood>.svg`: `hello`, `ok`, `champion`, `search`, `oops`, `stop`, `lost`, `focus`. Список эмоций в `src/lib/mascot.ts`.
- Анимация внутри SVG на CSS (дыхание, моргание, взмах, искорки); при `prefers-reduced-motion` выключена.
- `Mascot` (`src/components/mascot.tsx`): `<img>` с `alt=""`, `aria-hidden`, заданными размерами (без CLS), `loading="lazy"` кроме первого экрана. Без `cn`, чтобы не тянуть движок классов в клиентский JS через `error.tsx`.
- Где стоит:

| Место | Эмоция |
| --- | --- |
| Вход | `hello` |
| Смена пароля | `focus` |
| Логотип в боковом меню (`STUB(D-01)`) | `hello` |
| «Сегодня», шапка | есть кому напомнить или должники: `focus`; есть оплаты сегодня: `champion`; иначе `ok` |
| «Клиенты», «Напоминания», «Ещё» | `hello` |
| «Группы» | `ok` |
| «Отчёты» | `champion` |
| «Журнал» | `search` |
| «Настройки» | `focus` |
| Пусто: нечего напоминать, нет напоминаний в карточке | `ok` |
| Пусто: нет клиентов, групп, оплат клиента | `hello` |
| Пусто: никого не нашли, нет оплат за месяц, журнал и история пустые | `search` |
| Пусто: должников нет | `champion` |
| Пусто: сегодня оплат нет, раздел в разработке | `focus` |
| Ошибка экрана | `oops` |
| 403 «Нет доступа» | `stop` |
| 404 «Страница не найдена» (новая `src/app/not-found.tsx`, тексты на трёх языках) | `lost` |

- Скелетоны основных экранов держат место под персонажа (`PageHeaderSkeleton mascot`).

## Заметки на будущее
