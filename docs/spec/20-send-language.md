# 20. Выбор языка при отправке напоминания

Статус: todo
Зависит от: 19, D-17
Ветка: `step/20-send-language`
Навыки: `backend-development`, `ui-ux-design`, `browser-verification`

## Цель

Перед открытием WhatsApp администратор видит, на каком языке уйдёт сообщение, и может переключить его на русский, казахский или узбекский только для этого сообщения. Язык из карточки клиента остаётся языком по умолчанию. Решение владельца проекта от 2026-11-17 (D-17).

## Почему

На прогоне владелец поправил узбекский шаблон в «Настройках → Напоминания», а сообщение всё равно ушло на русском. Это не поломка: язык берётся из карточки клиента (шаг 19), а там по умолчанию стоит русский. Сейчас язык не виден в момент отправки, и понять это нельзя. Первым делом в шаге воспроизвести этот случай e2e-тестом: клиент с `ru`, правка `uz`-шаблона, текст на «Сегодня» русский. Если текст окажется не на языке карточки, это баг: сначала падающий тест, потом исправление.

## Что входит

- На «Сегодня» и в карточке клиента, рядом с текстом напоминания: переключатель «Русский / Қазақша / Ўзбекча». По умолчанию выбран язык из карточки. Смена языка сразу меняет текст предпросмотра и ссылку `wa.me`, без перезагрузки и без запроса к БД (шаблоны всех языков уже приходят в `reminder_context()`).
- Выбранный язык действует только на это сообщение. Карточка не меняется. Рядом короткая подсказка: «Язык клиента меняется в карточке».
- Запись «Чат открыт» хранит фактический шаблон: `record_reminder_opened()` принимает необязательный язык, берёт шаблон `(kind, locale)` и пишет его `template_id`. Нет шаблона на этом языке: русский, как в шаге 19.
- Язык виден явно: подпись над текстом «Сообщение на: Ўзбекча», пометка «черновик», если шаблон этого языка не правили.
- Тексты интерфейса на ru, kk, uz.
- `docs/admin-guide.md`: как отправить на другом языке и как поменять язык клиента навсегда.

## Что не входит

- Автоматический перевод текстов.
- Запоминание языка из переключателя в карточку (только вручную в карточке).
- Семьи и одно сообщение на нескольких детей: шаг 21.

## Критерии готовности

| # | Критерий | Как проверяем |
| --- | --- | --- |
| 1 | Клиент с `ru`, правлен `uz`-шаблон: по умолчанию текст русский, после выбора «Ўзбекча» в предпросмотре и в ссылке `wa.me` правленный узбекский текст | e2e `reminders.spec.ts`, `mobile` и `desktop` |
| 2 | Переключатель не меняет `clients.message_locale` | интеграция |
| 3 | `reminder_events.template_id` указывает на шаблон выбранного языка; неверный язык: отказ БД | интеграция |
| 4 | Повтор «Чат открыт» с другим языком не создаёт второе событие (`unique (payment_id, kind)`) | интеграция |
| 5 | Выбор шаблона по языку с откатом на русский | unit `template.test.ts` |
| 6 | Смена языка без новых запросов к БД; экран по-прежнему 2–3 запроса | e2e (сеть) |
| 7 | 390 и 1440 px, консоль без ошибок; JS первой загрузки ≤ 150 КБ | браузер, `first-load-js.spec.ts` |
