# 10. Импорт из тетради (CSV, Excel)

Статус: todo
Зависит от: 06
Ветка: `step/10-import`
Навыки: `backend-development`, `secure-coding`, `ui-ux-design`

## Цель

Перенести существующих клиентов из тетради (переписанной в Excel) за несколько минут, без дублей и без потери данных.

## Что входит

- Загрузка `.csv` (UTF-8 и Windows-1251, разделители `,` и `;`) и `.xlsx` до 2 МБ, только `owner` (и `admin`, если D-09 разрешит).
- Парсинг на сервере. Библиотека для xlsx выбирается по размеру и поддержке (обосновать в PR), в клиентский бандл не попадает.
- Столбцы: фамилия, имя, телефон, группа, дата окончания абонемента; сопоставление заголовков по синонимам («Фамилия», «Surname», «Тегі»…), ручное сопоставление, если не распознано.
- Предпросмотр: таблица со статусом строки (новая, дубль — уже есть, ошибка) и текстом ошибки рядом («Неверный телефон», «Группа не найдена — будет создана?»).
- Импорт в транзакции. Дата окончания из тетради создаёт запись `payments` типа `import_balance` (добавить тип отдельной миграцией, сумма 0, `period_end` = дата из файла, причина «перенос из тетради»). Так статус считается обычной функцией, а в истории честно видно, что денег системой получено не было.
- Строки с ошибками не импортируются, корректные импортируются одной транзакцией; отчёт показывает пропущенные строки и даёт скачать их файлом для исправления.
- Повторный импорт того же файла не создаёт дублей: ключ дедупликации (нормализованный телефон + фамилия + имя), хеш файла в `audit_log`.
- Ограничение частоты импорта. Audit.
- Шаблон файла для скачивания.

## Что не входит

Импорт истории оплат по месяцам.

## Критерии готовности

1. Unit: парсинг CSV в обеих кодировках и с обоими разделителями; xlsx с датами в разных форматах (`18.11.2025`, число Excel).
2. Unit: сопоставление заголовков по синонимам.
3. Интеграция: импорт 150 строк → 150 клиентов; повтор → 0 новых.
4. Интеграция: строка с ошибкой не импортируется, остальные импортируются; `client_status` для импортированных считается по дате окончания из файла.
5. Интеграция: файл > 2 МБ и неверный тип отклоняются.
6. E2E: загрузка → предпросмотр с ошибками → импорт → клиенты в списке со статусами по дате окончания.
7. Импорт 500 строк < 5 с локально.
