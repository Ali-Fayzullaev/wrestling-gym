# 19. Напоминания в WhatsApp на трёх языках

Статус: done
Зависит от: 09, 16, D-13
Ветка: `step/19-message-languages`
Навыки: `backend-development`, `ui-ux-design`, `browser-verification`

## Цель

Каждый клиент получает напоминание на своём языке: русском, казахском или узбекском (кириллица). Язык выбирается в карточке клиента; поменяли язык, и следующее сообщение сразу уходит на новом языке. Решение владельца проекта от 2026-11-17 (D-13).

## Что входит

- Миграция:
  - `clients.message_locale text not null default 'ru' check (in ('ru','kk','uz'))`;
  - `message_templates.locale` с той же проверкой, уникальность `(kind, locale)`; существующие шаблоны получают `ru`, добавляются черновые `kk` и `uz` для каждого вида (за 7 дней, за 1 день, в день окончания);
  - функции «Сегодня» и напоминаний берут шаблон по `(kind, clients.message_locale)`; нет шаблона на языке клиента: русский.
- Подстановки на языке шаблона: дата окончания (`formatDate` с локалью шаблона: «16 қаңтар», «16 январ»), сумма, название зала. Название зала одно (из «Настроек»), не переводится.
- Карточка клиента и форма «Новый клиент»/«Изменить»: поле «Язык сообщений» (Русский / Қазақша / Ўзбекча), по умолчанию русский. Видно и меняют `owner` и `admin`.
- «Настройки → Напоминания»: тексты по языкам (переключатель ru / kk / uz над шаблонами); подсказка, что клиенту уходит текст на его языке.
- Предпросмотр сообщения на «Сегодня» и в карточке на языке клиента; ссылка `wa.me` с этим текстом.
- Импорт: необязательный столбец «Язык» (синонимы «Язык», «Тілі», «Тили», «Language»; значения `ru/kk/uz`, «русский», «казахский», «қазақша», «узбекский», «ўзбекча»); пусто: русский.
- Тексты интерфейса на ru, kk, uz. Черновые шаблоны kk и uz помечены «черновик» до вычитки носителем (D-13 остаётся открытым в части вычитки).
- Снять `STUB(D-13)` в `src/features/reminders/template.ts`, `reminder-settings-form.tsx`.

## Что не входит

- Латиница для узбекского.
- Автоматический перевод текстов, которые пишет владелец: каждый язык он правит сам.
- Отправка без открытия чата (только `wa.me`, правило 3).

## Результат

- Миграция `20261117054205_message_languages.sql`: `clients.message_locale` (check, по умолчанию `ru`, grant на insert/update для обеих ролей); `message_templates.locale` (check), уникальность `(kind, locale)` вместо `(kind)`, `update (locale)` никому не выдан; черновые шаблоны kk и uz (`STUB(D-13)` до вычитки). `reminder_template_for()`: шаблон вида на языке клиента, иначе русский; по нему `record_reminder_opened()` пишет `template_id`. `reminder_context()` отдаёт шаблоны всех языков с `locale` и `edited`; `reminder_contact_json()`, `today_screen()`, `client_screen()` несут язык клиента. `client_screen()` дополнительно отдаёт вид напоминания для карточки (закончился: «в день окончания»; сегодня есть напоминание: его вид; иначе первое) и контекст напоминаний, по-прежнему один вызов. `create_client` и `update_client` с `p_message_locale` (старые версии удалены, чтобы не было перегрузки; `null` при изменении оставляет язык как есть, смена пишется в журнал полем `message_locale`). `import_clients()` принимает `message_locale` в строке. `update_reminder_settings()` пишет язык шаблона в журнал.
- Код: `pickTemplate()` и `reminderValues(..., locale)` в `template.ts` (дата и сумма на языке выбранного шаблона, в том числе когда русский подставлен вместо отсутствующего); `buildReminderText()` и `buildReminderLink()` в `reminders/service.ts`; язык в `today/service.ts` и `clients/service.ts`. Импорт: столбец `locale` (синонимы «Язык», «Язык сообщений», «Тілі», «Тили», «Language»), значения в `import/locale.ts`, ошибка строки `locale_invalid`; не русский язык показан в предпросмотре строки.
