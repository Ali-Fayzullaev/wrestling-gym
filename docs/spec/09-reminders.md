## Цель

Напоминание об оплате открывается в WhatsApp с готовым текстом в два нажатия, а система честно фиксирует только то, что знает: чат был открыт.

## Что входит

- `src/lib/whatsapp.ts`: `buildWaLink(phone, text)` → `https://wa.me/77011234567?text=<encodeURIComponent>`.
- `src/features/reminders/template.ts`: подстановка `{имя}`, `{дата_окончания}`, `{сумма}`, `{группа}`, `{название_зала}`; неизвестная переменная остаётся как есть и подсвечивается в предпросмотре; результат без лишних пробелов. Для ребёнка обращение к родителю (`parent_name`), если указан.
- Тип напоминания по `days_left`: `before_7`, `before_1`, `overdue` (дни из `settings.reminder_days`, `STUB(D-05)`).
- Кнопка «WhatsApp»: Server Action записывает `reminder_events` (`chat_opened`, кто, когда, шаблон; `on conflict (payment_id, kind) do nothing`), затем открывает ссылку. Ссылка открывается синхронно по клику (чтобы браузер не блокировал), запись события — параллельно, с повтором при ошибке сети.
- Подпись в строке после нажатия: «Чат открыт 14:32». Отдельная кнопка «Отметить отправленным» → `marked_sent`.
- Экран «Напоминания»: вкладки «Сегодня», «Просроченные», «История» (события с фильтром по дате и сотруднику).
- Подсказка на экране: «Отправляйте только с номера зала через WhatsApp Business».
- Шаблоны (только `owner`): список, редактирование, предпросмотр на реальном клиенте из сидов, audit изменений.
- Настройка дней напоминаний (только `owner`). Дни и шаблоны редактируются на одном экране, который открывается из «Настройки → Напоминания» (D-11). Типы показываются словами: «Первое напоминание (за 7 дней)», «Второе (за 1 день)», «В день окончания».
- История напоминаний в карточке клиента.

## Что не входит

Любая автоматическая отправка, WhatsApp API, боты.

## Критерии готовности

1. Unit: `buildWaLink` — номер без `+`, кириллица и казахские буквы, переносы строк, `&` и `#` закодированы.
2. Unit: подстановка шаблона, неизвестная переменная, отсутствующая сумма.
3. Интеграция: два нажатия → одна запись события; другой тип для того же абонемента → вторая запись.
4. Интеграция: `marked_sent` только из `chat_opened`; обратный переход и изменение других полей запрещены.
5. Интеграция: `admin` не может менять шаблоны и дни.
6. E2E: клик «WhatsApp» открывает `wa.me` с ожидаемым текстом (перехват `popup`/навигации), строка показывает «Чат открыт ЧЧ:ММ», клиент уходит из «Напомнить сегодня».
7. E2E: нигде в интерфейсе нет слов «отправлено»/«доставлено» до ручной отметки (поиск по тексту страницы).
8. E2E: предпросмотр шаблона.
9. `/security-review` (ПД в ссылке уходит только в WhatsApp, не в логи и аналитику).
