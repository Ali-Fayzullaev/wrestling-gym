# Приёмка сервиса с заказчиком

Цель: убедиться на настоящем телефоне администратора у входа в зал, что сервис заменяет тетрадь. Файл заполняется во время прогона: отметки, секунды, замечания, подпись.

## 1. Подготовка (до прихода заказчика, 15 минут)

1. Владелец входит на компьютере и добавляет администратора в «Настройки → Сотрудники» (например, «Суннат»), задаёт временный пароль и передаёт его лично.
2. Администратор входит на своём телефоне, меняет временный пароль на свой. Добавить сайт на главный экран: Chrome «Добавить на главный экран», Safari «Поделиться → На экран „Домой“».
3. Владелец создаёт тестового клиента: фамилия «Приёмка», имя «Тест», телефон владельца (чтобы проверочное сообщение пришло ему, а не реальному клиенту), любая группа.
4. Проверить, что в зале есть мобильный интернет; Wi-Fi на телефоне администратора выключить.

Оплаты в сервисе удалить нельзя (так задумано). Тестовые оплаты после приёмки отменяются сторно с причиной «приёмка», тестовый клиент уходит в архив (раздел 6). Тогда отчёт за месяц их не считает.

## 4. Обход на телефоне администратора

- [ ] Вход по почте и паролю; после выхода и повторного входа всё на месте.
- [ ] «Сегодня»: четыре счётчика нажимаются и открывают свои списки.
- [ ] «Напомнить сегодня» → «WhatsApp»: открылся чат с номером клиента и текстом. В строке написано «Чат открыт», а не «отправлено».
- [ ] «Отметить отправленным» после отправки в WhatsApp.
- [ ] «Клиенты»: поиск по фамилии, по телефону, казахскими буквами; фильтры по группе и статусу.
- [ ] Новый клиент: ребёнок с телефоном родителя, согласие отмечено.
- [ ] Карточка клиента: абонемент, история оплат, история напоминаний.
- [ ] Оплата Kaspi и наличными; «Отменить» в течение 10 минут.
- [ ] «Группы»: состав группы виден, изменить группу нельзя.
- [ ] «Ещё» → «Язык»: переключить на «Қазақша», пройти «Сегодня» и «Клиенты», затем «Ўзбекча», затем вернуть «Русский». Выйти и войти: выбранный язык сохранился. Переводы пока черновые (D-13): ошибки перевода записать в замечания.
- [ ] «Ещё» → «Тема»: тёмная тема читается в зале при ярком свете и вечером.
- [ ] Нет «Отчётов», «Журнала», «Настроек»; набранный вручную `/reports` открывает отказ.
- [ ] Крупные кнопки нажимаются пальцем с первого раза, текст читается без увеличения.

## 5. Обход на компьютере владельца

- [ ] «Отчёты»: оплаты за месяц совпадают с тетрадью за тот же период (если вели параллельно); смена месяца; выгрузка xlsx и csv открывается в Excel.
- [ ] Должники совпадают с тем, кого владелец считает должниками.
- [ ] «Журнал»: видны оплаты и отмены, сделанные на приёмке, с именем администратора.
- [ ] «Настройки»: название зала, номер WhatsApp, группы и цены, дни и тексты напоминаний, сотрудники. Изменение сохраняется и видно у администратора.
- [ ] Сторно старой оплаты с причиной; отчёт за месяц уменьшился.
- [ ] Импорт клиентов из файла (если у владельца есть список в Excel).
- [ ] Сброс пароля администратору: новый временный пароль, при входе обязательная смена.

## 6. После приёмки

1. Владелец делает сторно всех оплат тестового клиента с причиной «приёмка» и отправляет клиента «Приёмка» в архив.
2. Если что-то меняли в «Настройках» для проверки, вернуть нужные значения.
3. Замечания из раздела 8 разработчик переносит в задачи.

## 9. Открытые решения

Сервис работает по умолчанию из `docs/spec/90-open-decisions.md`. На приёмке по каждому вопросу нужен ответ заказчика или явное «отложить, работать как сейчас».

| ID | Вопрос | Как работает сейчас | Ответ заказчика |
| --- | --- | --- | --- |
| D-01 | Название, логотип, цвета | Название и номер WhatsApp меняются в «Настройках»; логотип текстовый, акцент красный | |
| D-02 | Виды абонементов, скидки | Только месяц, без скидок; сумму можно изменить при оплате | |
| D-03 | Продление от старой даты или от даты оплаты | Абонемент ещё действует: от его даты окончания; закончился: от даты оплаты | |
| D-05 | Тексты и дни напоминаний | За 7 дней, за 1 день и в день окончания; тексты владелец меняет в «Настройках» | |
| D-07 | Заморозка абонемента | Нет | |
| D-08 | Отметка посещений | Нет | |
| D-09 | Кто видит суммы | Администратор видит сумму оплаты в карточке и при отметке, но не отчёты; импорт только у владельца | |
| D-10 | Текст согласия на ПД и сообщения | Отметка «согласие получено», дата и кто; текст на проверке у юриста | |
| D-13 | Языки | Каждый сотрудник выбирает язык на «Ещё». Напоминания клиенту на языке шаблона, даты и суммы в них по-русски. Казахский и узбекский черновые: кто из носителей вычитает? | |
