# ui-ux-design

Характер: строгий, контрастный, спортивный. Но в первую очередь рабочий инструмент, им пользуются 50 раз в день у входа в зал с одного телефона.

## Токены

Все цвета только через CSS-переменные в `src/app/globals.css` (формат shadcn/ui, `oklch`), никаких hex в компонентах.

| Токен | Назначение |
| --- | --- |
| `--background`, `--foreground` | фон и текст; тёмная тема: графит, не чистый чёрный |
| `--card`, `--muted`, `--border` | поверхности и разделители |
| `--primary` | акцент (насыщенный красный; финальный цвет D-01) |
| `--status-active` | зелёный «Активен» |
| `--status-expiring` | жёлтый/янтарный «Скоро закончится» |
| `--status-expired` | красный «Долг» |
| `--status-none` | серый «Нет абонемента» |

Контраст текста не ниже WCAG AA (4,5:1, крупный 3:1) в обеих темах. Проверять при изменении палитры.
Тема: светлая, тёмная, системная; переключатель в «Ещё», выбор в cookie, без мигания при загрузке.

## Типографика и форматы

- Шрифт с кириллицей и казахскими буквами (ә ғ қ ң ө ұ ү һ і), через `next/font`, `display: swap` с подобранным fallback.
- Суммы и даты: `tabular-nums`. Суммы `25 000 ₸` (неразрывный пробел), даты «18 ноября», с годом только если не текущий.
- Форматтеры только из `src/lib/format.ts`, не писать `toLocaleString` в компонентах.

## Макет

- Mobile-first. Мобильный: нижнее меню из 4 пунктов «Сегодня», «Клиенты», «Группы», «Ещё», с подписями и иконками, учитывать `safe-area-inset-bottom`.
- `md` и шире: боковое меню; контент не шире 1200 px.
- Одно главное действие на экране. Области нажатия не меньше 44×44 px, основные кнопки строки («WhatsApp», «Оплатил») в зоне большого пальца.
- Формы на мобильном в sheet снизу, на компьютере в dialog. Числовые поля с `inputMode="numeric"`, телефон `inputMode="tel"`.

## Компоненты

shadcn/ui как основа. Свои общие компоненты в `src/components/`:
`StatusBadge` (цвет + текст + иконка), `Money`, `DateText`, `EmptyState`, `StatCard` (счётчик-ссылка), `PageHeader`, `ConfirmDialog` (только для необратимых), `ListSkeleton`.

## Состояния (каждый экран)

| Состояние | Как |
| --- | --- |
| Загрузка | `loading.tsx` со скелетоном той же геометрии, что контент (без CLS) |
| Пусто | `EmptyState`: что здесь будет и что сделать, с кнопкой действия |
| Ошибка | `error.tsx`: простыми словами, кнопка «Повторить», без технических деталей и ПД |
| Успех | toast на 4–5 с, для обратимых действий кнопка «Отменить» |

## Тексты

- Все строки в `src/i18n/ru.ts`. Короткие глаголы на кнопках: «Оплатил», «Сохранить», «В архив».
- Ошибки рядом с полем, по-человечески: «Номер должен начинаться с +7 и содержать 11 цифр».
- Подтверждение только для необратимого: сторно, архив, удаление.
- Не писать «отправлено» про WhatsApp, только «Чат открыт 14:32».
- Никаких выдуманных цифр, отзывов, логотипов. Логотип и название зала: заглушка `STUB(D-01)`.

## Анимации

150–200 мс, только чтобы показать, что произошло (появление toast, смена статуса строки). Всё отключается при `prefers-reduced-motion`.

## Чек-лист доступности

- [ ] Всё доступно с клавиатуры, порядок фокуса логичный, фокус виден (`focus-visible` кольцо).
- [ ] У каждого поля `<label>`, у иконок-кнопок `aria-label`.
- [ ] Статус не только цветом: текст плюс иконка.
- [ ] Контраст AA в обеих темах.
- [ ] Ошибки формы связаны с полем через `aria-describedby`, `aria-invalid`.
- [ ] Toast объявляется через `aria-live`.
- [ ] Масштаб до 200% без горизонтальной прокрутки.
- [ ] Lighthouse Accessibility 95+.
